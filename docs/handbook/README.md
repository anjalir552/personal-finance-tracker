# Scopewise handbook

Scopewise is a personal finance decision companion for people aged 18 to 30 in India. It isn't just an expense tracker. It's built to answer one question:

> **"Can I afford this without affecting my other goals?"**

This handbook explains how the app works, page by page, with every feature covered.

## Quick start

1. Open `index.html` in a browser. No install or sign-in is needed.
2. The app opens with **example data** for Aarav, a 24-year-old designer in Pune, so you can explore.
3. When you're ready, go to **Settings → Your data → Clear all data**, then follow the three set-up steps on **Overview**.

> Scopewise gives estimates to help you think a decision through. It isn't financial advice.
